## 0. 总地图：整条管线到底在算什么

```text
星系坐标 / 稳定哈希
        │
        ▼
┌───────────────────────────────┐
│ A. 定义生成算法               │  GeneratePlanetFromStableHash
│    5 轴随机 → 气候/色/地形/天体 │
└───────────────────────────────┘
        │ 冻结存档（Freeze）
        ▼
┌───────────────────────────────┐
│ B. 统一高度场算法             │  GetSurfaceNoise
│    噪声 → 大陆/海床/细节/山脊 │
└───────────────────────────────┘
        │ 同一函数被多处采样
        ├──────────────┬──────────────────┐
        ▼              ▼                  ▼
   C. 立方体球面素   D. 流式大球+LOD    E. 无限平面
   GenerateVoxel     Streaming+FarLOD   SampleInfiniteHeight
```

**必须先记住的设计原则：**

1. **定义一次、冻结一次**：过程星第一次访问后写入 `GalaxyGeneratedPlanetRecord`，形状不再变。  
2. **高度函数只有一个**：`VoxelQuadSphereTerrain.GetSurfaceNoise`。球壳、进近低模、平面地块都问它。  
3. **物理尺 ≠ 表现尺**：物理用米制算重力/大气；场景里用代理球半径（大星约 2000）摆几何。

## 1. 算法 A：从坐标到星球定义

### 1.1 稳定哈希：为什么同一位置永远同一颗星

2D 星系里，坐标 `(x, y)` 与世界种子 `worldSeed` 混合：

```text
HashCoordinate(seed, (x,y), salt):
    value = (uint)seed XOR salt
    value = Mix(value XOR x)
    value = Mix(value XOR RotateLeft(y, 32))
    return value
```

`Mix` 是 SplitMix64 风格搅动（右移异或 + 大质数乘法），把输入打散成看起来随机、但**完全确定**的 64 位整数。

星际 3D 生成器也会算出一个 `stableHash`，再调用同一个 `GeneratePlanetFromStableHash`。

### 1.2 StableRandom：可复现的伪随机流

```text
构造: state = seed（若为 0 则用黄金比例常数）
Next():
    state += 0x9E3779B97F4A7C15
    return Mix(state)
Value(): 取 Next 的高位 → [0,1) 浮点
```

同一 `stableHash` → 同一随机序列 → 同一颗星。

### 1.3 五轴采样（定义生成的“基因”）

依次掷出：

| 变量 | 用途 |
|------|------|
| `temperature` | 热度 → 气候、雪线、石层深度 |
| `moisture` | 湿度 → 气候、表土层、海洋倾向、天气 |
| `geology` | 地质活跃 → 山高、洞穴、火山气候、资源数量 |
| `atmosphere` | 大气 → 有无气、密度、天气开关、海洋视觉 |
| `crystal` | 水晶倾向 → Crystal 气候、装饰权重、异色海洋 |

颜色大致：

```text
hue = repeat(0.58 + temp*0.36 + crystal*0.22 - moisture*0.18)
saturation = lerp(0.48, 0.9, max(geology, crystal))
value = lerp(0.58, 0.92, atmosphere)
mapColor = HSV(hue, sat, value)
surfaceColor / rockColor 再由 mapColor 偏移得到
```

再取 `seed = random.NextNonZeroInt()` —— 这才是**高度场噪声种子**。

### 1.4 气候分类算法（决策树）

`PlanetClimateClassifier.Classify(t, m, g, c)`，按优先级：

```text
if crystal >= 0.68           → Crystal
else if geology >= 0.72
      and temperature >= 0.55 → Volcanic
else if temperature <= 0.28   → Tundra
else if temperature >= 0.62
      and moisture >= 0.58    → Tropical
else if temperature >= 0.62
      and moisture <= 0.38    → Desert
else if moisture >= 0.48      → TemperateForest
else                          → Barren
```

固定 ID（origin/verdant/…）可走 `TryGetFixedClimate` 覆盖。

### 1.5 地形参数算法 `CreateTerrain`

从三轴映射到 `PlanetTerrainSettings`（大星常用尺度）：

```text
oceanBias = clamp01(moisture*0.52 + rand*0.38 + (1-temp)*0.1)

continentScale     = lerp(0.00055, 0.0018, rand)      // 大陆波长（越大大陆越小块）
continentHeight    = lerp(55, 125, lerp(rand, geology, 0.5))
detailScale        = lerp(0.004, 0.014, rand)
detailHeight       = lerp(8, 34, geology)
ridgeHeight        = lerp(2, 48, geology²)            // 地质越猛山越高
continentThreshold = lerp(0.43, 0.61, oceanBias)      // 越大海越多
continentWarp      = lerp(0.2, 1.15, rand)
continentSharpness = lerp(0.72, 1.8, geology)
mountainMask       = lerp(0.38, 0.66, rand)
oceanFloorDepth    = lerp(0.32, 0.92, geology)
terraceStrength    = 约 28% 概率开启，强度随 geology
surfaceLayerDepth  = lerp(0.6, 2.2, moisture)         // 湿润 → 更厚泥层
stoneDepth         = lerp(4, 12, 1 - temp*0.35)
generateCaves      = geology > 0.18
caveScale / threshold / clearance 随 geology、rand
shapeVersion       = 2   // 当前形状版本
```

**读参口诀：**

- `continentScale` 小 → 大陆块更大更连贯  
- `continentThreshold` 大 → 更难成陆 → 海洋多  
- `ridgeHeight` / `geology²` → 山脉夸张度  

### 1.6 天体参数算法 `CreateCelestialProfile`

1. 物理半径 `radiusMeters ∈ [1.5e6, 1e7]`（幂次偏置，小星更多）  
2. 请求重力再夹到该半径下密度可行区间，反推密度与 \(\mu=GM\)  
3. `atmosphere > 0.16` 才有气  
4. **表现层固定**：`StreamingLargeSphere`，代理半径 `LargePlanetRadius = 2000`  
5. 表现大气顶约 700～900，标高约 95～150（压扁，盖住进近巡航带）

### 1.7 视觉权重与天气（摘要）

`CreateVisualProfile` 把五轴变成连续权重：

```text
tropical ∝ moisture * SmoothStep(0.35→1, heat)
forest   ∝ moisture * (1 - |heat-0.58|*1.3)
desert   ∝ (1-moisture) * f(heat)
tundra   ∝ (1-heat) * ...
volcanic ∝ geology² * f(heat)
```

以及是否有海洋、雪线、装饰密度等。  
`CreateWeather`：大气太薄则关天气；否则按湿度/地质/温度/水晶添加 Clear/Rain/Thunderstorm/Ashfall/Sandstorm/CrystalDust 等预设。  
过程星际：`rivers.enabled = false`。

### 1.8 冻结

首次访问后定义写入存档。之后加载冻结记录，**不再**重新跑 `GeneratePlanetFromStableHash`。  
这保证「昨天那座山今天还在」。

## 2. 算法 B：统一高度场 `GetSurfaceNoise`（必须彻底搞懂）

文件：`VoxelQuadSphereTerrain.cs`  
输入：`localPosition`（通常是球面上某点，或平面映射回的 3D 点）、`seed`、`PlanetTerrainSettings`  
输出：相对参考地表的高度偏移（正=山，负=海床）

若 `shapeVersion < 2` 走旧版 `GetLegacySurfaceNoise`（Perlin 大陆+细节+脊）。当前过程星用 **v2**。

### 2.1 底层砖块 1：Hash01 → 格子随机值

对整数格点 `(x,y,z)` 与种子：

```text
hash = x*374761393 + y*668265263 + z*2246822519 + seed*3266489917
hash = (hash XOR (hash>>13)) * 1274126177
hash = hash XOR (hash>>16)
return (hash & 0x00FFFFFF) / 16777215   ∈ [0,1]
```

### 2.2 底层砖块 2：ValueNoise（三线性插值）

1. 取点所在立方体 8 个角的 `Hash01`  
2. 分数部分用平滑函数 `Smooth01(t)=t²(3-2t)`（Hermite 平滑，导数在 0/1 为 0）  
3. 沿 x→y→z 三次线性插值  

结果：邻近点连续，远处可变化。

### 2.3 底层砖块 3：FractalNoise（分形叠加）

```text
sum=0, amp=1, freq=1, norm=0
for octave in 0..octaves-1:
    sum  += ValueNoise(point * freq, seed + octave*1619) * amp
    norm += amp
    freq *= 2.03
    amp  *= 0.51
return sum / norm
```

- 低频大振幅 → 大陆轮廓  
- 高频小振幅 → 细褶皱  
- 归一化后输出约在 [0,1]

### 2.4 Domain Warp：先揉坐标再采样

```text
continentPoint = localPosition * continentScale
warp.x = FractalNoise(continentPoint*0.58 + 偏移A, seed+101, 3)
warp.y = FractalNoise(... seed+211 ...)
warp.z = FractalNoise(... seed+307 ...)
continentPoint += (warp*2 - 1) * continentWarp
```

把规则网格采样点推歪，避免大陆边界太“格子气”。  
`continentWarp` 越大，海岸越扭曲。

### 2.5 大陆 / 海洋分解（核心）

```text
continentNoise = FractalNoise(continentPoint, seed+401, 5)     // ≈[0,1]
signedContinent = (continentNoise - continentThreshold) * 2.45

landMask = Smooth01( InverseLerp(-0.06, 0.18, signedContinent) )
// signed 从略负到略正时，landMask 从 0→1 平滑过渡

land  = max(0, signedContinent)^continentSharpness * continentHeight
ocean = -max(0, -signedContinent)^0.72 * continentHeight * oceanFloorDepth
```

理解：

| 量 | 含义 |
|----|------|
| `signedContinent > 0` | 陆地侧，抬升 |
| `signedContinent < 0` | 海洋侧，下凹 |
| `continentSharpness` | 陆地剖面锐度（幂次） |
| `oceanFloorDepth` | 海床相对大陆高度的深度比例 |
| `landMask` | 0～1，后面细节/山都乘它，避免海里乱长山 |

### 2.6 细节层

```text
detailPoint = localPosition * detailScale
detail = (FractalNoise(detailPoint, seed+809, 3) - 0.5)
       * detailHeight
       * Lerp(0.22, 1.0, landMask)
```

海上只有 22% 细节强度，陆地满强度。

### 2.7 山脊层（Ridge）

```text
ridgeSource = FractalNoise(detailPoint*0.36 + continentPoint*0.18, seed+1201, 4)
ridge = 1 - |2*ridgeSource - 1|      // 把峰值变成山脊线
ridge = ridge³                         // 压尖，山更陡峭

highlandMask = Smooth01(InverseLerp(
    mountainMask-0.22, mountainMask+0.18, continentNoise))

mountains = ridge * ridgeHeight * landMask * highlandMask
```

只有「是陆地」且「大陆噪声够高（高地）」才长山。

### 2.8 梯田、钳制

```text
height = ocean + land + detail + mountains

if terraceStrength > 0 and height > 0:
    terraceSize = max(0.75, detailHeight*0.22)
    terraced = round(height / terraceSize) * terraceSize
    height = lerp(height, terraced, terraceStrength)

maxH = continentHeight*0.82 + detailHeight*0.45 + ridgeHeight*0.8
maxD = continentHeight * oceanFloorDepth * 0.72
return clamp(height, -maxD, maxH)
```

### 2.9 手算检查清单（自学用）

给定一点 `p` 与设置，你应能逐步算出：

1. warp 后的 `continentPoint`  
2. `signedContinent` 正负 → 陆还是海  
3. `landMask` 是否接近 0/1  
4. 四项之和再 clamp  

改一个参数时预测地形变化，再对照游戏，是最快的吃透方式。

## 3. 算法 C：立方体球（Quad-Sphere）与体素填充

### 3.1 为什么用立方体球？

纯经纬度网格在两极会挤成一条线。  
做法：把**立方体六个面**映射到球上，每面一张规则 UV 网格。

### 3.2 Cube → Sphere 映射

`GetFaceCubePoint(face, u, v)`：把面内 `(u,v)∈[-1,1]` 变成立方体表面点。  

`CubeToSphere`（等面积风格近似）：

```text
对立方体点 (x,y,z)（已在面上）:
x' = x * sqrt(1 - y²/2 - z²/2 + y²z²/3)
y' = y * sqrt(1 - x²/2 - z²/2 + x²z²/3)
z' = z * sqrt(1 - x²/2 - y²/2 + x²y²/3)
再 normalize 得径向方向
```

比简单 `normalize(cubePoint)` 更均匀，减少极区/棱边畸形。

### 3.3 体素格子中心

```text
radial = GetRadialDirection(face, cellU, cellV, gridSize)
distance = planetRadius - depth - 0.5
center = planetCenter + radial * distance
```

- `depth = 0` 更靠外  
- `depth` 增大 → 往地心走  
- Legacy：`gridSize≈100`；大星：`LargePlanetFaceGridSize = 2048`  
- `ChunkSize = 16`

### 3.4 体素类型判定 `GenerateVoxelWithSurfaceNoise`

```text
surfaceNoise = GetSurfaceNoise(radial * surfaceReferenceRadius, seed, settings)
surfaceRadius = surfaceReferenceRadius + surfaceNoise - riverCarve
depthFromSurface = surfaceRadius - radialDistance

if depthFromSurface <= 0:          Air          // 在地表之外
if depth 属于最内 innerSolid 层:   Stone        // 内核强制石头
voxel = (depthFromSurface <= surfaceLayerDepth) ? Dirt
      : (depthFromSurface >= stoneDepth) ? Stone : Dirt

if generateCaves
   and depthFromSurface > caveSurfaceClearance
   and IsCave(...):                Air          // 挖洞
```

`IsCave`：把位置用 `caveScale` 缩放后，取三轴 Perlin 均值，大于 `caveThreshold` 则挖空。

### 3.5 网格化

每个 chunk（含 padding 邻格）→ `VoxelQuadSphereMesher` 建三角网格与碰撞。  
这是标准体素贪婪/面剔除类网格构建（细节在 mesher 内），输入是填好的体素数组。

## 4. 算法 D：大球流式与 Far LOD

大星不可能一次生成 `6 × 2048² × 深度` 个体素。

### 4.1 活跃流式

`VoxelQuadSphereWorld`：

- `ActiveStreamingChunkRadius = 4`：玩家/船周围半径约 4 个 chunk  
- 协程 `GenerateStreamingRegionIncremental`：按帧预算逐步生成  
- 优先着陆点附近，再向外扩  

### 4.2 飞行只读流式

`BeginReadOnlyFlightStreaming`：进近时不挖改地形，只在前方走廊生成碰撞用地块，保证飞得过去、撞得实。

### 4.3 Far LOD

远处用 `PlanetLodMeshBuilder` 直接采样 `GetSurfaceNoise` 建低模球壳（进近常用约 48～64 细分），再加海洋球、大气壳。  
近处体素上来后，Far LOD 可淡出/挖洞，避免穿模。

### 4.4 三种模式对照

| 模式 | 半径量级 | 生成策略 |
|------|----------|----------|
| `LegacyFullSphere` | 100 | 整星增量生成 |
| `StreamingLargeSphere` | ~2000 | 流式体素 + Far LOD |
| `InfinitePlanar` | 代理球参数仍在定义里 | 着陆后切平面世界 |

## 5. 算法 E：球变平面（完整吃透）

这是「远看是球、近玩是平地」，但高度仍来自同一颗星。

### 5.1 几何模型

选中着陆方向单位向量 \(\hat{a}\)（锚点）。  
建切平面正交基：

```text
BuildTangentBasis(anchor):
    reference = (|dot(anchor, up)| < 0.98) ? up : forward
    east  = normalize(cross(reference, anchor))
    north = normalize(cross(anchor, east))
```

平面上的点 \((x,z)\) 对应三维采样点：

\[
\mathbf{p}(x,z) = \hat{a}\,R + \hat{e}\,x + \hat{n}\,z
\]

其中 \(R\) = `celestial.radius`（代理球半径）。

高度：

\[
h(x,z) = \mathrm{GetSurfaceNoise}(\mathbf{p}(x,z),\; seed,\; terrain)
\]

代码即 `SampleInfiniteHeight`。

**注意：** 这里用的是**切平面展开**（局部欧氏近似），不是把整颗星做等距投影。  
离锚点越远，几何误差越大——但玩法只在锚点附近无限拼地块，足够用。

### 5.2 锚点怎么选 `FindBestLandAnchor`

在球面上用斐波那契式候选点（黄金角螺旋）扫一圈：

```text
for i in 0..N-1:
    y = 1 - 2*(i+0.5)/N
    r = sqrt(1-y²)
    θ = GoldenAngle * i
    dir = (cosθ·r, y, sinθ·r)
    h = SampleHeight(definition, dir)   // 仍是 GetSurfaceNoise
    记录最高点
    若 h > 海平面间隙 且 坡度不太陡 → 记为可步行候选
return 最佳可步行点；若没有则退回全球最高点
```

保证落地多半在陆地上、不太陡。

### 5.3 平面网格如何建 `BuildInfiniteChunkMesh`

对每个 chunk 坐标 `(cx, cz)`：

```text
size ≈ 128
resolution ≈ 16
centerX = cx * size
centerZ = cz * size
step = size / resolution

1) 多采一圈高度样本（含邻点，给法线用）
2) 对每个顶点 (localX, localZ):
      worldX = centerX + localX
      worldZ = centerZ + localZ
      h = SampleInfiniteHeight(...)
      vertex = (localX, h, localZ)
      normal ≈ normalize( -(hE-hW)/(2step), 1, -(hN-hS)/(2step) )
      color 按高度在 rockColor↔surfaceColor 间插值
3) 生成三角形索引 → Mesh + Collider
```

### 5.4 流式与浮点原点

- 视野半径约 2 → 大约 5×5 地块跟着玩家  
- 走近生成、走远回收  
- 玩家离本地原点超过约 **2048** → rebase：平移世界，把数字压回小范围，防 float 抖动  

### 5.5 和球体素的关系（易混点）

| 问题 | 答案 |
|------|------|
| 平面是另一套噪声吗？ | **不是**，同一 `GetSurfaceNoise` |
| 平面坐标直接当经纬度吗？ | **不是**，是切平面上的米制偏移 |
| 走太远还像原星球吗？ | 局部像；极远会偏离球面几何，但同一种子高度场仍连续 |
| InfinitePlanar 刷随机树吗？ | 当前实现里随机装饰流通常关掉 |

另有 `ProjectPlanarPointToSphere`：把平面点投回单位球方向（用于坡度估计等），与高度采样用的「不归一化切点」用途不同，读代码时别混。

## 6. 附属算法（吃透主干后补齐）

### 6.1 海洋

海洋球半径 ≈ `radius + oceanLevel * maximumTerrainElevation`。  
平面模式用 `seaHeight = oceanLevel * maxElevation` 做海面高度。  
水深 = 海面高度 − 地形高度（正为水）。

### 6.2 装饰 / 资源

`PlanetDecorationCatalog.BuildSpawnPlan`：按气候 + `forestWeight` 等视觉权重选 prefab。  
运行时按坡度、离水距离、间距拒绝采样。  
资源：`CreateResources` 按 geology/crystal 决定种类数与密度。

### 6.3 进近消费链

```text
锁定星球定义
  → PlanetLodMeshBuilder 采样高度建低模球
  → 海洋 + 大气视觉
  → BeginReadOnlyFlightStreaming（前方碰撞）
  → 着陆
       ├ InfinitePlanar → InfinitePlanarSurfaceWorld + Streamer
       └ 否则 → VoxelQuadSphereWorld 流式体素
  → EntryCoordinator 分阶段：地形→水→船→玩家→Ready
```

## 7. 端到端数据流（对照调试用）

```text
GalaxyCoordinate / Interstellar hash
  → HashCoordinate / stableHash
  → StableRandom
  → (t,m,g,a,c) + seed + PlanetTerrainSettings + Celestial + Visual
  → Freeze
  → 任意世界位置 p
        GetSurfaceNoise(p, seed, terrain) → h
  → 分支：
        体素: surfaceRadius = R + h - river → Dirt/Stone/Air/Cave
        LOD:  顶点径向位置 = (R + h) * dir
        平面: p = aR + e x + n z → h → 顶点 (x,h,z)
```
