# 城市区块难度生成算法

## 一、系统边界

正式流程固定为：玩家选择关卡难度 → 城市 PCG 按该难度生成一座城市 → 玩家进入城市 → EDPCG 只负责普通小怪的名单、刷新、攻击许可与压力闭环。

城市难度和 EDPCG 压力是两种不同数据：

- 城市难度回答“玩家处在这个空间里，留守或转移时有多难生存”。
- EDPCG 压力回答“当前这一帧实际投入了多少敌人、枪线和攻击许可”。
- Boss 不进入普通小怪 EDPCG。
- 城市 PCG 不用敌人数量伪造空间难度，EDPCG 也不反向改写城市几何。

## 二、固定生成顺序

同一个任务种子只生成一座城市，不再派生多个完整城市后挑选。

1. 建立8×8战术网格。
2. 完成地块角色分配与相邻地块合并。
3. 一次性生成道路骨架；后续局部修正不得移动道路。
4. 生成敌人入口和任务设施预留。
5. 外围最高楼作为固定几何上下文先进入枪线计算，但不参与难度平均。
6. 从中心格开始，每次只从已生成区域的四邻接前沿选择下一格。
7. 根据全城目标总量、已提交格实际总量和剩余格数，求出下一格的预算反馈目标。
8. 当前格同时构造3～5种候选，从密集遮挡一直覆盖到近乎完全开放。
9. 每个候选临时加入城市，重新求解所有已完成地块的枪线与最低风险路径。
10. 选择全城目标误差最小且不会把剩余目标推离可达区间的候选，再正式提交。
11. 生成法定战术实体和天际线锚点，并用最终规划几何重新验收。
12. 主体建筑全部完成后，依次加入连廊、电线和风场；每加入一种
    后处理渠道，都重新求解全城难度，最后用实体包围盒统一验收。

`localCorrectionCount` 记录该格实际比较的候选数量；`greedyRequestedDifficulty`、`greedyCandidateOpenness` 和剩余预算字段记录完整提交过程。报告里的城市候选次数固定为1，不能把区块候选误报成多座城市。

## 三、外围最高楼规则

8×8网格的外围一圈承担城市天际线和战斗边界职责：

- 基础建筑强制使用最高楼带。
- 法定道路、玩家航路和敌人入口仍保留净空，不允许为了“最高楼”堵死关卡。
- 外围楼参与枪线遮挡、物理可达性和最终碰撞验证。
- 外围格不参与关卡平均难度，也不能成为最低风险逃逸路径的目标。

因此外围不会把关卡平均值虚高，也不会出现玩家通过逃到城市边界把红格洗绿的漏洞。

## 四、每格的目标难度

关卡档位先产生一个全城平均目标，再按战术角色加减：

- 恢复区显著低于平均。
- 遮挡区略低于平均。
- 主机动区与垂直转换区略低于平均。
- 暴露区、攻击区和战术 choke 高于平均。
- 破坏区与牵引区小幅高于平均。

低档增加整体遮挡密度和高度，高档允许连续开放地块与大暴露盆地，但所有档位仍受道路、飞行净空、转弯半径和任务设施预留约束。正式目标平均值覆盖约18%～82%的静态空间难度，避免所有档位挤在中等区间。

## 五、枪线威胁计算

一个约200米的大格不能只用中心的一根射线代表。规划阶段对每格采样：

- 中空层中心与四个内角。
- 低空层中心。
- 高空层中心。

建筑内部的点不计入可飞体积。每个可飞样本搜索正式路线与入口附近可建立的远程枪位，并检查：

- 枪位到玩家样本不超过420米。
- 敌机5米机体通道和射击走廊不穿建筑。
- 来火所属水平扇区。
- 从预警到弹丸到达的时间。
- 是否形成有角度分离的交叉火力。

单个可见方向只表示潜在接触，不直接等于高难度。样本火力成本由以下因素共同形成：

- 被威胁的可飞体积比例。
- 地图上可建立枪线的方向覆盖。
- 当前关卡允许体现的并发方向强度。
- 最早命中的紧迫度。
- 交叉火力。

格子火力成本是所有可飞样本的平均。这样一条楼缝不会把整格染红，大面积无遮挡空间也不会被少量建筑洗绿。

## 六、生存难度不是固定权重相加

旧公式“火力×60%＋脱离困难×响应需求×28%＋机动困难×12%”已经废弃。

原因是：

- 安全格本来就不需要脱离，出口少不能让它凭空变难。
- 机动困难不应独立加分，它只应决定路径是否存在以及需要飞多久。
- 玩家真正做的是在“留在原地”和“沿某条路线离开”之间选择。

当前公式为：

`区块生存难度 = min（留守火力成本，最低风险转移成本）`

当留守火力低于安全阈值时，直接使用留守成本，不搜索脱离。

当留守火力较高时，图搜索寻找火力至少下降一个有效档位的地块。每条边的代价为：

`边暴露成本 = 两端格火力平均值 × 飞行时间`

最低风险转移成本包含起点不可避免的首轮压力和整条路径的暴露时间积分。只有转移成本确实低于留守成本时，格子才会因存在安全转移方案而降低难度。

图边只能由真实可飞走廊产生。转弯、爬升和净空不会单独占一个难度百分比，而是进入边的存在性与飞行时间。

风场没有脱离玩家运动方向的“顺风场”或“逆风场”标签。生成器也不
预测玩家最后会走哪条路线。对于每一对可飞邻格，A→B 与 B→A 是两条
独立的有向边：系统先计算该线段穿过风场盒体的精确长度比例，再用
飞行方向和风向的点积区分顺风、逆风或侧风，并按真实强度倍率修正
该边耗时。随后最低风险路径照常在全部可执行边中选择成本最低者。

因此，一片风只有在它确实覆盖玩家可选路径时才影响该格；若存在完全
绕开的更优路线，它不会被硬算成难度。静态 PCG 使用风场有效占空比的
期望值做小幅末端校准，实时阵风仍由运行时物理决定。

## 七、为什么每生成一格都要重算旧格

最低风险路径是全局图问题。新格可能：

- 新增一个更近的安全格。
- 连通两片原本断开的区域。
- 用高楼挡住旧格的一组枪线。
- 阻断旧的最短路径，迫使玩家绕行。

因此每个候选临时落位后，系统都会重算全部已生成格的最低风险路径。旧格不会在候选提交后被随意增高或减低；它受到的变化必须在当前候选的总评分里提前体现。候选不合适就换当前格方案，而不是回头篡改旧格。

## 八、剩余危险预算与贪心选择

设内部有效格总权重为 `W`，全城目标为 `T`，已提交格重新计算后的危险总量为 `S`，剩余权重为 `R`：

`剩余格平均要求 = (T × W - S) / R`

当前格在这个平均要求上叠加自身战术角色偏移，得到预算反馈目标。每个候选提交后再次计算剩余平均要求；如果它低于零或高于当前档理论可表现上限，说明该候选会让后续格无论怎样生成都无法收敛，评分会获得高额不可达惩罚。

候选代价由当前格目标误差、预测全城平均误差、剩余预算不可达误差、已生成格局部误差以及安全格/高危格比例共同组成。只有最终代价最低的候选会被提交。战术功能楼、任务设施、恢复区构件和边界墙不作为可调候选，但会在候选试算时作为固定几何参与枪线判断。

## 九、编辑器颜色

- 绿色：留守火力低，或已有低暴露安全选择。
- 黄色：存在可读威胁，但留守或短距离转移仍可处理。
- 橙色：留守压力高，最低风险路线也需要明显暴露。
- 红色：多向火力、快速命中或长距离高暴露转移共同形成高生存成本。
- 灰蓝色：外围最高楼边界，不计入难度平均。

选中格必须同时显示：目标难度、留守火力、最终生存难度、最低风险路径格数、路径时间和沿途暴露。不能再只显示“脱离困难”和“机动困难”两个含义模糊的百分比。

## 十、最终验收

规划通过不代表实体城市一定通过。连廊、电线、伴生楼和真实预制体碰撞体完成后，系统用最终几何快照重新计算：

- 每格火力与生存难度。
- 安全格、高危格和平均难度是否符合档位目标。
- 道路、飞行路线和任务设施是否保持可达。

最终实体快照不合格时，正式关卡必须失败返回，不允许静默降级到自然地图，也不允许让 EDPCG 用更多敌人掩盖城市空间错误。
