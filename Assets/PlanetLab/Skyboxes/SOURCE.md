# PlanetLab selected skyboxes

These assets were selectively imported from the user's local package:

`D:\untiy素材\Unity3D_220种精美高清天空盒_AllSky - 220+ Sky   Skybox Set_V5.2.0`

PlanetLab includes 25 selectively imported six-sided skyboxes. Formal planar
planet surfaces use one fixed material per `PlanetClimate`: Barren, Temperate
Forest, Desert, Tropical, Tundra, Volcanic, and Crystal. This keeps each
planet type visually distinct and stable across saves and chapter missions.
The older seeded five-template selection remains only as a compatibility
fallback for custom or incomplete libraries. Formal space scenes are
intentionally unchanged.

The original package's license and redistribution terms still apply to all
imported textures and materials.
